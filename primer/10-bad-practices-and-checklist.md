# Bad practices and guardrail checklist at a glance

> **Your account, your responsibility.** Read the [notice](00-read-this-first.md#before-you-start-your-account-your-responsibility) before you follow any step.

Facts on this page were checked on 2026-10-23. Prices, Free plan terms and console labels change; the linked pages give the details and the AWS pages to check.

## Bad practices

| Bad practice | What can go wrong | Covered on |
|---|---|---|
| Signing in as the root user for everyday work | The root user has full access to everything in the account, including billing and closing the account. If its session or password leaks, the whole account goes with it. Only a few tasks need it. | [02](02-secure-the-root-user.md), [03](03-your-everyday-admin-identity.md) |
| Creating long-lived access keys for a person, above all for the root user | A key works from anywhere, without MFA, until someone deletes it. Keys leak through code repositories, chats and screenshots. | [04](04-command-line-without-access-keys.md) |
| Building anything before budgets and alerts exist | Nothing warns you about spending until the bill arrives or the credits are gone. Even with alerts, cost data arrives hours to a day late. | [05](05-money-alarms.md) |
| Making an S3 bucket public to "fix" an access error | Anyone on the internet can reach what is in it. It undoes the safe default that blocks public access. | [06](06-safe-defaults.md) |
| Opening SSH or RDP to the whole internet (`0.0.0.0/0`) | Anyone on the internet can try to log in to your server. Trusted Advisor flags it. | [06](06-safe-defaults.md) |
| Starting a paid service's free trial without a reminder (Paid plan) | The trial turns into billing without asking you. | [06](06-safe-defaults.md) |
| Working in a Region you don't use | Resources there are easy to forget, and they keep costing even if you turn the Region off. | [06](06-safe-defaults.md), [07](07-habits-for-every-lab.md) |
| Stopping a resource instead of deleting it | Disks, snapshots, Elastic IP addresses and database backups keep costing. | [07](07-habits-for-every-lab.md) |
| Turning on IAM Identity Center, or joining AWS Organizations, on the Free plan | The account moves to the Paid plan for good, and you can no longer use or earn Free Tier credits. | [00](00-read-this-first.md), [03](03-your-everyday-admin-identity.md) |
| Choosing an **Upgrade plan** button without deciding to | The move to the Paid plan can't be undone; after that, you pay for anything your credits don't cover. | [00](00-read-this-first.md), [09](09-leaving-cleanly.md) |
| Putting real or sensitive data in a Free plan account | AWS's terms say Free plan accounts aren't for sensitive data, and the account and its contents are deleted after the plan ends. | [00](00-read-this-first.md), [09](09-leaving-cleanly.md) |

## Guardrail checklist

Every guardrail from pages 01 to 07, in order, with the Well-Architected pillar it serves and the best practice ID where one fits.

### [Page 01](01-create-your-account.md): create your account

- [ ] Sign up with the advanced sign-up link and choose the Free plan. [01](01-create-your-account.md) · Cost optimization (design principle "[Implement Cloud Financial Management](https://docs.aws.amazon.com/wellarchitected/latest/framework/cost-dp.html)"; no single best practice)
- [ ] Use an email address that exists only for this account, in an inbox you secure. [01](01-create-your-account.md) · Security · [SEC01-BP02](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_securely_operate_aws_account.html)
- [ ] Use a unique root password generated by a password manager. [01](01-create-your-account.md) · Security · [SEC02-BP01](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_enforce_mechanisms.html)
- [ ] Use a phone number you will keep. [01](01-create-your-account.md) · Security · [SEC01-BP02](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_securely_operate_aws_account.html)
- [ ] Pay with a card you watch closely; expect a USD $1 verification hold for 3 to 5 days. [01](01-create-your-account.md) · Cost optimization (design principle only, loose fit)
- [ ] Give the account a name with no personal information. [01](01-create-your-account.md) · Security (general privacy hygiene; no single best practice)
- [ ] Switch to US East (N. Virginia), `us-east-1`, and check the Region selector before every lab. [01](01-create-your-account.md) · Cost optimization · [COST02-BP05](https://docs.aws.amazon.com/wellarchitected/latest/cost-optimization-pillar/cost_govern_usage_controls.html)
- [ ] Stay on free Basic Support. [01](01-create-your-account.md) · Operational excellence · [OPS07-BP06](https://docs.aws.amazon.com/wellarchitected/latest/operational-excellence-pillar/ops_ready_to_support_enable_support_plans.html) (by contrast)

### [Page 02](02-secure-the-root-user.md): secure the root user

- [ ] Add a passkey as the root user's MFA. [02](02-secure-the-root-user.md) · Security · [SEC01-BP02](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_securely_operate_aws_account.html), [SEC02-BP01](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_enforce_mechanisms.html)
- [ ] Sign out, sign back in with it, then add a backup MFA device. [02](02-secure-the-root-user.md) · Security · [SEC01-BP02](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_securely_operate_aws_account.html), [SEC02-BP01](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_enforce_mechanisms.html)
- [ ] Confirm the root user has no access keys. [02](02-secure-the-root-user.md) · Security · [SEC02-BP02](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_unique.html), [SEC01-BP02](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_securely_operate_aws_account.html)
- [ ] Check the contact details and add billing, operations and security alternate contacts. [02](02-secure-the-root-user.md) · Security · [SEC10-BP01](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_incident_response_identify_personnel.html)
- [ ] Turn on IAM user and role access to billing information. [02](02-secure-the-root-user.md) · Cost optimization · [COST03-BP05](https://docs.aws.amazon.com/wellarchitected/latest/cost-optimization-pillar/cost_monitor_usage_config_tools.html)
- [ ] Know where root activity shows up: CloudTrail Event history and the IAM credential report. [02](02-secure-the-root-user.md) · Security · [SEC04-BP01](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_detect_investigate_events_app_service_logging.html)

### [Page 03](03-your-everyday-admin-identity.md): your everyday admin identity

- [ ] Set a password policy of at least 14 characters (we use 16) that blocks reuse of the last 24 passwords ([CIS AWS Foundations Benchmark](https://www.cisecurity.org/benchmark/amazon_web_services) v5.0.0). [03](03-your-everyday-admin-identity.md) · Security · [SEC02-BP01](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_enforce_mechanisms.html)
- [ ] Create an `Admins` group with the `AdministratorAccess` policy. [03](03-your-everyday-admin-identity.md) · Security · [SEC02-BP06](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_groups_attributes.html), [SEC03-BP02](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_permissions_least_privileges.html)
- [ ] Create one IAM user for yourself in that group, and use it for daily work. [03](03-your-everyday-admin-identity.md) · Security · [SEC02-BP01](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_enforce_mechanisms.html)
- [ ] Protect the IAM user with a passkey and a backup MFA device. [03](03-your-everyday-admin-identity.md) · Security · [SEC02-BP01](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_enforce_mechanisms.html)
- [ ] Don't turn on IAM Identity Center on the Free plan. [03](03-your-everyday-admin-identity.md) · Security · [SEC02-BP04](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_identity_provider.html) (a deliberate exception)

### [Page 04](04-command-line-without-access-keys.md): the command line without access keys

- [ ] Use CloudShell for command-line labs. [04](04-command-line-without-access-keys.md) · Security · [SEC02-BP02](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_unique.html)
- [ ] On your own computer, use `aws login` with AWS CLI version 2.32.0 or later. [04](04-command-line-without-access-keys.md) · Security · [SEC02-BP02](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_unique.html)
- [ ] Create no access keys; if one ever exists, keep it secret and delete it soon. [04](04-command-line-without-access-keys.md) · Security · [SEC02-BP03](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_secrets.html), [SEC02-BP05](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_identities_audit.html)

## Things that upgrade a Free plan account

Any of these moves a Free plan account to the Paid plan (as of 2026-10-23). The move can't be undone.

| Action | Notes |
|---|---|
| Choosing **Upgrade plan** yourself | The buttons appear in many places in the console. AWS's FAQ says your remaining credits still apply to your bills until they expire. |
| Joining or creating an organization in AWS Organizations | AWS's terms say you can then no longer use or earn Free Tier credits. |
| Turning on IAM Identity Center in a way that creates an organization | It creates an organization, so the row above applies. AWS's Identity Center guide says the credits expire immediately. The Identity Center page showed no warning on 2026-10-23. |
| Setting up an AWS Control Tower landing zone | Listed by AWS as an automatic upgrade. |
| Joining the AWS Partner Network | Listed by AWS as an automatic upgrade. |
| Creating an AWS Professional Services contract | Listed by AWS as an automatic upgrade. |
| Enrolling in an Enterprise Agreement with AWS | Listed by AWS as an automatic upgrade. |
| Buying an AWS Skill Builder Team subscription | Listed by AWS as an automatic upgrade. |
| Marking the account as HIPAA or SEC compliant | Listed by AWS as an automatic upgrade. |

AWS doesn't say whether the credits survive the automatic upgrades that don't involve AWS Organizations. Check the live pages: [Choosing a plan](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/free-tier-plans.html) (AWS Billing User Guide), [AWS Free Tier Terms](https://aws.amazon.com/free/terms/), [AWS Free Tier FAQs](https://aws.amazon.com/free/free-tier-faqs/) and [Enable IAM Identity Center](https://docs.aws.amazon.com/singlesignon/latest/userguide/enable-identity-center.html), all checked 2026-10-23.
